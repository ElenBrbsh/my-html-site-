# 🧠 Практическая работа: аудит рабочего пространства и проект улучшения

Этот проект — учебная веб-экосистема, разработанная для проведения комплексного анализа и модернизации рабочего места / учебной аудитории. Он помогает студентам пройти путь от аудита до публикации собственного HTML-отчёта с эргономическими, техническими и организационными предложениями.

## 🎯 Цель работы

Показать, как технические, эргономические и дизайнерские решения влияют на эффективность, комфорт и рациональность использования пространства. Итогом становится многостраничный сайт с фотографиями, AI-визуализациями, сметой и защитой проекта.

## 🧩 Структура проекта

| Файл | Содержание |
|------|-------------|
| `index.html` | Главная навигационная страница с маршрутом работы. |
| `student_html_guide.html` | Инструкция: как редактировать HTML, использовать ИИ-помощников и не сломать код. |
| `student_checklist_interactive.html` | Интерактивный чек-лист оценки рабочего места (9 категорий, автоподсчёт баллов, вывод сильных/слабых сторон). |
| `student_report_template.html` | Шаблон отчёта, автоматически подтягивающий данные из чек-листа. |
| `student_infrastructure_project.html` | Полное проектное задание: паспорт объекта, команда, аудит с фото, смета, AI-визуализации, эргономика, зоны отдыха, серверный узел, TCO. |
| `student_publish_site_guide.html` | Пошаговая инструкция по публикации сайта на GitHub Pages. |
| `было1.jpeg` — `было3.jpeg` | Реальные фотографии текущего состояния аудитории (до улучшения). |
| `стало1.jpg` — `стало5.jpg` | AI-визуализации будущего пространства (после улучшения). |

## 🚀 Как использовать

1. **Скачайте или склонируйте репозиторий.**
2. Откройте `index.html` в браузере — это главное меню.
3. Последовательно пройдите этапы:
   - Инструкция по HTML и ИИ.
   - Интерактивный чек-лист (оценка своего рабочего места).
   - Шаблон отчёта (заполняется автоматически из чек-листа).
   - Проектное задание по закупке оборудования и эргономике.
   - Инструкция по публикации на GitHub Pages.
4. Замените фотографии и AI-визуализации на свои.
5. Опубликуйте готовый сайт на GitHub Pages и получите публичную ссылку.

## 🛠️ Технологии

- **HTML5**, **CSS3** (адаптивный дизайн, CSS-переменные, гриды/флексы).
- **Vanilla JavaScript** (без внешних библиотек): сохранение данных в `localStorage`, динамическое добавление/удаление блоков, чек-листы, автоподсчёт процентов, предпросмотр изображений.
- **Print-friendly стили** — страницы можно сохранять в PDF.

## 📚 Особенности

- Чек-лист включает **9 категорий** (от эргономики до логики закупки для организации) — всего **~40 критериев**.
- Инфраструктурный проект содержит:
  - Паспорт проекта (объект, цель, аудитория).
  - Управление командой до 4 человек с личными выводами каждого.
  - Загрузку реальных фото и AI-визуализаций с промптами.
  - Расчёт TCO (совокупной стоимости владения).
  - Чек-лист качества из 28 пунктов с автоматической готовностью в процентах.
- Все формы сохраняют черновик в браузере — можно закрыть страницу и продолжить позже.
- Инструкция по публикации позволяет превратить локальный HTML-файл в работающий сайт за 5–10 минут.

## 📦 Пример использования

Группа студентов:

1. Выбрала аудиторию 6115 с серыми столами и жёсткими скамейками.
2. Провела фотофиксацию .
3. Заполнила чек-лист, получила 72/92 балла (78%) — «хорошая организация, есть точки для улучшения».
4. Предложила заменить мебель на велюровые кресла (тёмно-зелёные) и коричневые столы со встроенными беспроводными зарядками.
5. С помощью Kandinsky сгенерировала 5 визуализаций, приложив промпты.
6. Рассчитала бюджет (~850 000 руб.), срок службы 5–7 лет, план внедрения на 3 месяца.
7. Опубликовала проект на GitHub Pages и сдала ссылку преподавателю.
